Relative rates with lequel

These relative pronouns adjust in gender and number to the reference word. They are used to refer to persons or things that stand by prepositions or prepositional expressions.

Unlike the companion quel stands lequel as pronouns without a following reference word.

If these pronouns with the preposition à The following forms are formed:

  • à + lequel = auquel
  • à + laquelle = à laquelle
  • à + lesquels = auxquels
  • à + lesquelles = auxquelles
Les projets auxquels je participe sont intéressants.
The projects, an denen I participate, are interesting.

With the preposition de These forms arise:

  • de + lequel = duquel
  • de + laquelle = de laquelle
  • de + lesquels = desquels
  • de + lesquelles = desquelles
Le musée près duquel j'habite est magnifique.
The museum, in dessen Near I live is beautiful.
These forms are used only if they preposition. For simple additions with de in the relative rate dont is used.
